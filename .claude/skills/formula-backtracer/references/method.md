# method — 정량 방법 상세

## 기준선: devig 마감확률

각 경기의 한 market(예: moneyline home/away)에서 마감 price로:
```
raw_home = 1/price_home
raw_away = 1/price_away
p_home   = raw_home / (raw_home + raw_away)   # vig 제거(양측 합=1 정규화)
```
- 마감 = `latest_odds` 뷰(각 game_id·market·side 마지막 스냅샷).
- 3-way(축구 승/무/패)면 세 side를 함께 정규화.
- **정규화가 기준선을 정직하게 만든다.** raw 1/price는 vig 때문에 합>1이다.

## 평가지표

라벨 y∈{0,1}, 예측확률 p:
```
log-loss = -mean( y·ln(p) + (1-y)·ln(1-p) )      # 주지표, 낮을수록 좋음
brier    =  mean( (p - y)^2 )                      # 보조
```
- ln(0) 폭발 방지: p를 [1e-6, 1-1e-6]로 clip.
- 3-way면 다항 log-loss.
- **공식 점수는 항상 기준선 점수와 같은 셋에서 나란히.**

## 시간순 분할 (누수 방지)

```
game_date 오름차순 정렬 →  [ 학습 60% ][ 검증 20% ][ 홀드아웃 20% ]
```
- 랜덤 KFold 금지: 시계열은 과거로 미래가 샌다.
- 홀드아웃은 **가장 최근** 구간, STEP 3에서 **한 번만**.
- 팀 폼 등 롤링 특징은 **각 시점 이전 경기만** 사용(경기 자신·미래 제외).
