1. 시작하기

커멘드센터는 브라우저에서 바로 사용할 수 있는 도구입니다. 설치할 필요가 없어요.

1

주소 입력

브라우저 주소창에 아래 주소를 입력하고 Enter를 누르세요.

https://joker8awesome.github.io/workflow-builder/

💡 크롬(Chrome) 브라우저를 권장합니다. 폰트와 기능이 가장 잘 동작해요.
2

첫 화면 확인

화면이 열리면 왼쪽에 워크플로우 목록, 가운데 큰 캔버스(작업 공간), 오른쪽에 속성 패널이 보입니다.

💡 처음이라 아무것도 없어도 괜찮아요. 아래에서 차근차근 따라 하면 됩니다.
3

화면 구성 알아보기

영역역할
⬅️ 왼쪽 사이드바워크플로우 목록, 새로 만들기, 검색
🎯 가운데 캔버스블록(노드)을 배치하고 연결하는 작업 공간
➡️ 오른쪽 속성선택한 블록의 이름, 설명, 담당자 등을 편집
⬆️ 상단 메뉴실행, AI, 팀, 공유, 내보내기 등 주요 기능

2. 첫 워크플로우 만들기

가장 쉬운 방법은 내장 예시를 설치하는 것입니다. 예시를 고쳐서 내 것으로 만들면 금방 익숙해져요.

1

예시 워크플로우 설치

왼쪽 사이드바에서 템플릿을 클릭 → 📦 내장 예시에서 원하는 것을 선택 → 설치 → 클릭

예시무엇을 하나요?
콘텐츠 제작아이디어 → 초안 → 검수 → 승인 → 배포 (7단계)
데이터 처리CSV 입력 → 가공 → 품질 확인 → DB 저장 (6단계)
승인 프로세스요청 → 승인 게이트 → 처리 (5단계)
2

빈 화면에서 직접 만들기

위쪽 ＋ 새 워크플로우 버튼 클릭 → 이름 입력 → 캔버스에서 우클릭 → 노드 추가

💡 우클릭하면 메뉴가 나와요. 시작 → 프로세스 → 종료 순서로 3개만 만들어도 실행할 수 있는 워크플로우가 완성됩니다.
3

이름 바꾸기

오른쪽 속성 패널에서 워크플로우 이름을 클릭 → 원하는 이름 입력 → 자동 저장됩니다.

💡 모든 변경은 자동 저장됩니다. 저장 버튼을 누를 필요가 없어요!

3. 노드(블록) 9종

노드는 워크플로우의 한 단계입니다. 각자 다른 역할을 해요.

노드색상역할언제 쓰나요?
시작초록워크플로우의 출발점모든 워크플로우의 첫 번째
프로세스파랑일반 작업 (스크립트, 메시지 등)데이터 정리, 메시지 전송 등
판단주황Yes/No로 분기"완료됐나요?" 같은 질문
승인갈색사람 확인 대기중요한 단계 전 승인 받기
감독보라여러 작업을 나눠 병렬 실행동시에 여러 일 처리
검토청록결과 확인/검증오류 없는지 점검
연결주황CSV/JSON/API/DB에서 데이터 가져오기외부 데이터 입력
투표핑크여러 에이전트 다수결여럿이 결정할 때
종료빨강워크플로우의 끝마지막에 배치
⚠️ 노드에 마우스를 올리면 예상 시간/역할 설명이 나와요. 어떤 노드인지 헷갈릴 때 활용하세요.

4. 노드 연결하기

노드와 노드를 선으로 연결하면 순서가 생깁니다. "시작 → 프로세스 → 종료"처럼 흐름을 만들어요.

1

연결 핸들 찾기

노드 오른쪽 가장자리에 작은 원(핸들)이 있어요. 이 원을 드래그하면 선이 그려집니다.

2

선 긋기

노드 오른쪽 핸들 → 누른 채 → 다음 노드로 드래그 → 놓기

💡 선이 가까운 노드에 자석처럼 붙어요. 놓을 때 초록색으로 강조되면 연결 성공!
3

분기 만들기 (판단 노드)

판단 노드에서 연결하면 자동으로 Yes / No 두 개의 선이 만들어집니다.

예: "승인 여부" 판단 → Yes면 배포로, No면 초안 작성으로

4

노드 이동/삭제

이동: 노드를 누른 채 끌어서 원하는 위치에 놓기
삭제: 노드 클릭 → Delete 키 누르기
복사: 노드 클릭 → Ctrl+D

5. 실행하기

만든 워크플로우를 실제로 돌려보세요. 실행하면서 어디서 멈추는지, 무슨 일이 일어나는지 눈으로 볼 수 있어요.

1

실행

상단 메뉴의 초록색 ▶ 실행 버튼 클릭

노드가 순서대로 강조되며 실행되고, 하단에 현재 상태가 표시됩니다.

2

시뮬레이션 (안전하게 미리보기)

상단 메뉴 ⋯ 더보기 → 시뮬레이션 클릭

실제로 실행하지 않고 예상 경로·시간·비용을 보여줍니다. 위험 없이 미리 확인할 수 있어요.

3

실행 결과 보기

⋯ 더보기 → 트레이스: 각 단계가 얼마나 걸렸는지 타임라인으로 표시
통계: 실행 횟수, 성공률, 병목 확인

⚠️ GitHub Pages(웹 버전)에서는 시뮬레이션 실행만 가능합니다. 실제 에이전트/DB 연동은 로컬 서버에서 동작해요.

6. AI 에이전트 등록하기

에이전트는 워크플로우의 담당자입니다. 각 노드에 "누가 이 일을 하는지" 지정하면 협업이 가능해져요.

1

팀 탭 열기

상단 메뉴에서 팀 클릭 → ＋ 에이전트 등록 클릭

2

에이전트 정보 입력

이름, 담당자, 역할, 머신스펙(예: 8vCPU/16GB), 구축환경(예: Docker), 워크스페이스 경로를 입력하고 저장

3

노드에 에이전트 배정

캔버스에서 노드 클릭 → 오른쪽 속성의 담당 에이전트에서 선택

노드에 에이전트 이름 배지가 표시됩니다. 누가 무슨 일을 하는지 한눈에 보여요.

💡 배정 안 된 노드는 점선으로 표시돼요. 빠뜨린 담당을 찾기 쉬워요.
4

에이전트 대시보드

⋯ 더보기 → 대시보드: 에이전트별 담당 노드 수, 완료/진행 상태 확인
⋯ 더보기 → 거버넌스: 신뢰 점수, 자율성 레벨 확인

7. 공유 & 저장

1

자동 저장

모든 변경은 자동으로 저장됩니다. 위쪽에 "로컬 저장" 표시가 보이면 정상이에요.

💡 웹 버전은 이 브라우저에 저장됩니다. 다른 브라우저에서는 목록이 비어 보일 수 있어요.
2

내보내기 / 가져오기

내보내기: 상단 메뉴 → 워크플로우를 JSON 파일로 저장
가져오기: 상단 메뉴 → 저장한 JSON 파일을 다시 불러오기

💡 다른 사람에게 워크플로우를 보낼 때는 JSON 파일이 가장 확실해요.
3

공유 링크

상단 메뉴 공유 클릭 → 링크가 복사됩니다. 링크를 받은 사람은 읽기 전용으로 볼 수 있어요.

⚠️ 공유 링크는 서버가 켜져 있을 때만 동작합니다 (로컬 서버 전용).
4

단축키 모음

단축키기능

Ctrl+Shift+Z다시 실행

8. 자주 묻는 질문

Q. 워크플로우가 사라졌어요!

웹 버전은 브라우저 로컬 저장소를 사용합니다. 같은 브라우저에서 접속하면 다시 나타나요. 다른 브라우저/시크릿 모드에서는 보이지 않습니다.

Q. 노드가 안 움직여요

노드 위에 툴팁(설명 박스)이 떠 있으면 잠시 헷갈릴 수 있어요. 마우스를 옆으로 이동하면 사라집니다. 노드 몸통을 눌러서 드래그해 보세요.

Q. 실행 버튼을 눌렀는데 아무 일도 안 일어나요

시작 노드가 있는지, 시작 → 다음 노드로 선이 연결됐는지 확인하세요. 빈 워크플로우나 연결이 끊긴 워크플로우는 실행할 게 없어요.

Q. AI 판단 노드가 뭐예요?

판단 노드에 LLM 판단을 설정하면, AI가 질문(예: "이 초안이 배포 가능한가?")에 Yes/No로 답해 분기합니다. 조건식 대신 AI 판단을 쓸 수 있어요.

Q. 승인 노드에서 멈췄어요

승인 노드는 사람이 직접 승인해야 진행됩니다. 화면에 승인 창이 뜨면 확인/반려를 선택하세요. 일정 시간(5분)이 지나면 자동으로 반려 처리됩니다.

Q. 모바일에서도 되나요?

네! 휴대폰에서도 사용할 수 있습니다. 하단에 실행/AI/통계 등 버튼이 나타나고, 터치로 노드를 움직일 수 있어요.

Q. 의견을 보내고 싶어요

상단 메뉴의 의견 버튼을 눌러 자유롭게 적어주세요. 개발자에게 전달됩니다.
